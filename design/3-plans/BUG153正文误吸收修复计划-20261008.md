# BUG-153 正文误吸收修复计划

**目标：** 含乘除符号的自然语言仍作为正文保留，Attention 公式 (3) 继续完整补全。

**设计：** 现有续块判定在全文任意位置搜索中缀运算符，会把 `We set x × y = 1.` 放在正文守卫之前通过。将特殊放行限定为文本起始的数学变量（含下标、幂）直接接 `·/×/÷`；其他块继续走既有正文判断与数学碎片规则。保持同栏、邻接几何、图表排除和未吸收续块哨兵不变。相比英文动词黑名单，起始结构约束不依赖有限词表；相比重写全部正文分类器，改动范围更小。

**技术：** Python、正则、PyMuPDF、pytest。

3. 在 `lib/equation_regions.py` 收紧续块正则与解释，确认正文反例转绿，既有真实公式和 detached 反例仍通过。

- `model · min(...)` 等真正数学续块正常补全；确实无法吸收的续块仍保留原文待复核。
