## 四个入口的接力

| 用户意图 | scripts/ 入口 | 实际业务流程 |
| --- | --- | --- |
| 同时转 Markdown、准备摘要材料 | `process_pdf.py` | 对应 core → Markdown main → 成功后摘要材料 main（复用） |
| 只转 Markdown | `pdf_to_markdown.py` | 对应 core → 结构化正文 → 提取资产 → 质量筛选 → 题注旁插图 → 渲染/报告 |
| 只准备带图阅读材料 | `summarize_pdf.py` | 对应 core → 默认提取资产；复用模式只核对已有 index 与文本 |
| 提取/调试图表 | `extract_pdf_assets.py` | 对应 core → 预检/文本/版式 → Figure → Table → 上下文 → 可选后精修 → 对账/索引 |

主要调用都是 Python 函数 `main(args)`，包装层用模块加载或导入方式进入 core；这里没有子进程工作队列。图中的泳道表示职责，不表示并发工作线程。

## 需要准确理解的边界

1. **摘要不由 summarize 脚本生成。**脚本准备材料并打印建议路径。Agent 必须阅读全文和图表图片，再撰写默认中文的阅读摘要、解释关键图表。
2. **process 不重复抽图。**先转 Markdown，再通过 `--reuse-existing` 核对并复用同一资产目录、全文文件。核对内容包括 index 结构、PDF 文件名与 SHA256 前 16 位；核对失败直接返回失败，不会自动重抽。
3. **正文与资产提取会各自准备结构化文本。**Markdown 先构建文档对象，提取器随后还会准备纯文本、结构化全文及基础版式；资产复用不等于全过程只读取一次 PDF。
4. **两种版式机制分别标注。**`layout-driven` 基础文字/栏位模型默认 on；`layout-backend` 语义区域后端默认 off。语义后端提前取得区域，但集成报告、配对和 `pipeline` 精修发生在默认图表提取及上下文生成之后。缺失依赖/后端异常会回退；精修候选不通过守卫时保留原框。
5. **质量门影响正文插图。**`markdown_insertable` 优先按已有 `status` 判断，仅 `accepted` / `accepted_with_margin` 可插入；`review_required` / `rejected` 不插正文、进入 conversion report 的 omitted。只有旧索引缺少 `status` 时，才按复核标记与警告兜底。找到同页、同类型、同编号的真正题注后，把截图插在其前或后；找不到题注的可插入资产追加到“提取资产”。
6. **状态与退出码是两条信号。**提取非零退出时，Markdown 可能已写出，但转换报告为 failed，非零退出码继续向 process 传播；process 停止摘要材料步骤。仅有 omitted 时报告为 review，但 Markdown 入口仍返回 0，process 会继续。
7. **无题注续表自动恢复。**Table 提取结束时依据结构证据恢复邻页片段；`--allow-continued` 单独控制重复题注条目，不是自动续表的总开关。
8. **当前参数能力按实现解释。**`--ocr auto/force` 目前只记为 `not_implemented`，没有 OCR 执行流程；`--tables auto/structure` 当前仍处理截图资产，没有接入结构化表格 Markdown 输出。

## 文件产物

默认以 PDF 所在目录为输出根；Markdown 指定 `--out` 时，默认 `images/` 与 `text/` 相对于 Markdown 所在目录，process 同步复用这些位置。测试另遵守仓库 tests/results 的布局约束。

| 产物 | 用途 |
| --- | --- |
| `paper.md` | 结构化正文与相对图片链接 |
| `text/paper.txt`、`text/gathered_text.json` | 摘要全文与结构化段落 |
| `images/*.png`、`images/index.json` | 图表截图与题注、页码、框、状态、源 PDF 哈希等索引 |
| `images/layout_model.json`、`images/figure_contexts.json` | 默认版式启用时的文字版式，以及图表正文上下文 |
| `text/markdown_blocks.json`、`text/conversion_report.json` | Markdown 数据块与转换状态/omitted |
| `images/run.log.jsonl` | 运行事件与 run_end 统计 |
| `layout_integration.json`、`layout_pairing.json`、`layout_refinement.json` | 可选语义 Layout 相关报告，位于资产目录 |
| 可选 manifest CSV、debug 叠图 | 清单导出与裁剪调试 |
| `paper_阅读摘要-YYYYMMDD.md` | Agent 撰写的最终摘要；脚本只是建议该路径 |

PNG 实际在提取/精修时渲染，text 也在证据准备阶段写出；主图的“汇总与索引落盘”卡片归并这些产物，不表示所有文件都到最后一步才创建。
