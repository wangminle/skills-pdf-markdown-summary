# tests/eval — 版本化评测器（A0-3）

> 日期：2026-07-31
> 口径依据：`docs/PDF图表提取技术迭代实施方案-20260731.md` §2（验收口径）与 §4 A0-3/A0-4。

## 用途

从 `docs/3-experiments/20260728-pymupdf4llm-layout-bbox/scripts/` 的一次性实验脚本
（03 GT/IoU/coverage/purity、05 分歧统计、09 裁决）迁出的**版本化评测器**。
实验目录已 gitignore，只保留探索脚本；可复用的指标计算全部在这里。

相对实验脚本修正了二次复核发现的三处口径缺陷：

1. **资产键** = `document_id + kind + ident + caption_page + occurrence + group_id`
   （原实验只用 type+ident，忽略页码，造成虚假跨页分歧——如 Gemini Table 11 p12 被映射到 p63）；
2. **legacy/预测匹配强制校验页码**，跨页不一致计入 `cross_page_mismatch` 诊断，不允许配对；
3. **配对器为全页一对一**（一框最多配一次），并输出**候选重复占用统计**
   （取消一对一约束时同一预测框会被多少条 GT 认领）。
   历史基线：**8 组 / 16 条资产**（2026-07-28 二次复核数字）；A2 完成后，8 份 benchmark 的 `duplicate_occupancy.n_groups` 已归零。

## 文件

| 文件 | 职责 |
| --- | --- |
| `keys.py` | BBox 几何（含多框并集/交集面积）、资产键构造、GT/预测规范化、一对一贪心配对 + 重复占用统计 |
| `metrics.py` | 方案 §2.6 六项指标：数量对齐率（漏检/多检分列）、截断率（§2.5 判定层，≤1pt 容差，二值）、配对正确率（一对一）、过量混正文率（框内非资产正文行 >1 行）、content coverage（多 bbox 并集，0.995 仅筛查）、crop purity（不设阈值仅观察） |
| `run_eval.py` | CLI 入口：GT 目录 + 预测目录 → 六项指标 JSON + 重复占用统计。GT 为空时友好提示、正常退出（标注未开始是正常状态） |
| `convert_labelme_to_gt.py` | LabelMe JSON → gt.json 转换器，像素 → PDF 点（DPI=108，与实验 `01_extract_layout.py` 的 `fitz.Matrix(1.5,1.5)` 一致） |
| `selfcheck.py` | 自检（非 pytest 套件）：`python tests/eval/selfcheck.py` 或 `run_eval.py --selfcheck` |

## 用法

```bash
python tests/eval/run_eval.py \
    --gt-dir tests/annotations \
    --pred-root docs/3-experiments/20260728-pymupdf4llm-layout-bbox/legacy \
    --pdf-root tests/basic-benchmark \
    --out tests/results/<yyyymmdd-xxx>/eval.json
```

- `--pred-root` 支持两种布局（predictions.json 优先）：实验 legacy 的
  `<document_id>/predictions.json`（`predictions` 键）与正式提取产物的
  `<document_id>/images/index.json`（`items` 键，`id`/`type`/`page`/`final_bbox`
  字段自动映射）；目录名空格自动归一化为下划线 document_id。
- 有预测但无 GT 的文档会在 stderr 友好提示并跳过（标注未完成是正常状态）。
- `--pdf-root` 可选；不提供则「过量混正文率」跳过（该指标需要页面文本行）。
- 本目录**不是 pytest 套件**，不要放 `test_*.py` 文件。

## 已知简化（后续版本收紧）

- 混正文判定用「行中心/半高落入框内且与所有 GT 元素框无交叠」近似 §2.4 的
  「一行」操作性定义（未实现 1.3 倍行高与上下边缘位置约束）；
- 截断判定要求元素被**单个**预测框完整包含（不允许元素跨多框拼合）；
- 配对为贪心（tier 0 同 ID 优先、其次 IoU），规模小足够；如需最优可换匈牙利。
